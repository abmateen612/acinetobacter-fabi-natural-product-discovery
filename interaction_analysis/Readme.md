# Protein–Ligand Interaction Analysis

This directory contains 2D protein–ligand interaction diagrams generated using **Discovery Studio Visualizer 2025**. Each file represents one selected compound and is named according to its NPASS compound ID.

The diagrams illustrate interactions between docked natural product candidates and the FabI binding site (PDB: 6AHE), with the NAD cofactor retained.

The interaction profiles include:

- Hydrogen bonds
- Hydrophobic interactions
- Other protein–ligand contacts
- Interacting residues and contact distances

These interaction analyses were used to compare binding interactions and support the selection of four compounds for subsequent 100 ns molecular dynamics simulations.
